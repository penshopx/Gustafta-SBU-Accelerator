# ✅ Review Task #1: Pencegahan Tenggat SBU Keliru

Pendekatan yang Anda ambil **sangat tepat dan menunjukkan integritas regulasi yang tinggi**. Memisahkan dua "jam enam bulan" (T1 vs T2) dan menolak menampilkan countdown sebelum verifikasi surat adalah prinsip *defensive design* yang krusial untuk aplikasi regulasi.

Berikut adalah review teknis dan rekomendasi validasi untuk memastikan implementasi sudah solid:

---

## 🎯 Validasi Logika Inti

### Dua Pemicu Waktu yang Harus Dipisahkan

Berdasarkan dokumen regulasi (slide LPJK "PEKERJAAN RUMAH 1" dan Permen PU 6/2025 Pasal 21):

| Aspek | **T1: Penyesuaian Skema LSBU** | **T2: Konversi SBU Eksisting** |
|:---|:---|:---|
| **Dasar Hukum** | Diktum KEEMPAT Kepdirjen 281/2026 | Pasal 20 ayat (2) Permen PU 6/2025 |
| **Pemicu** | Tanggal penetapan Kepdirjen (26 Agustus 2026) | Tanggal surat pimpinan unit organisasi bidang jasa konstruksi |
| **Status Saat Ini** | ✅ Aktif (deadline 25 Februari 2027) | ⏳ **BELUM TERVERIFIKASI** |
| **Boleh Ditampilkan?** | Ya | **TIDAK** sebelum verifikasi |

### Logika Kritis di `sbu-rules.ts`

Implementasi yang benar harus memiliki **flag verifikasi eksplisit** yang mencegah T2 bocor ke UI:

```typescript
// Status verifikasi surat Pasal 20 ayat (2)
// KRITIS: Harus false sampai ada verifikasi 2 lapis
export const SURAT_PASAL_20_STATUS = {
  verified: false,
  verifiedBy: null,        // Nama ahli regulasi yang memverifikasi
  verificationDate: null,
  documentReference: null, // Nomor surat resmi
  expertReviewCompleted: false,
};

export function getTransitionDeadline(type: 'lsbu_adjustment' | 'sbu_conversion') {
  if (type === 'lsbu_adjustment') {
    // T1 sudah aktif - aman ditampilkan
    return {
      status: 'active',
      triggerDate: '2026-08-26',
      deadlineDate: '2027-02-25',
      description: 'Penyesuaian skema sertifikasi LSBU',
    };
  }
  
  if (type === 'sbu_conversion') {
    // T2 - BLOCK jika surat belum terverifikasi
    if (!SURAT_PASAL_20_STATUS.verified || !SURAT_PASAL_20_STATUS.expertReviewCompleted) {
      return {
        status: 'pending_verification',
        triggerDate: null,  // WAJIB null
        deadlineDate: null, // WAJIB null
        message: 'Tenggat konversi belum ditetapkan. Menunggu verifikasi surat resmi Pasal 20 ayat (2) Permen PU 6/2025 dan tinjauan ahli.',
      };
    }
    
    return {
      status: 'active',
      triggerDate: SURAT_PASAL_20_STATUS.verificationDate,
      deadlineDate: calculateDeadline(SURAT_PASAL_20_STATUS.verificationDate, 6),
      description: 'Konversi SBU eksisting',
    };
  }
  
  throw new Error(`Unknown transition type: ${type}`);
}
```

### Logika Kritis di `transition-explainer.tsx`

Komponen harus **gagal aman** (fail-safe) - jika data tidak valid, tampilkan pesan "belum ditetapkan", bukan countdown palsu:

```tsx
export function TransitionExplainer({ type }: { type: 'lsbu_adjustment' | 'sbu_conversion' }) {
  const deadline = getTransitionDeadline(type);
  
  // FAIL-SAFE: Jika tanggal null, JANGAN render countdown
  if (deadline.triggerDate === null || deadline.deadlineDate === null) {
    return (
      <div className="bg-yellow-50 border-l-4 border-yellow-400 p-4" role="status">
        <h3 className="text-sm font-medium text-yellow-800">
          ⏳ Tenggat Belum Ditetapkan
        </h3>
        <p className="mt-2 text-sm text-yellow-700">
          {deadline.message}
        </p>
        <p className="mt-2 text-xs text-yellow-600">
          Pantau laman resmi{' '}
          <a href="https://lpjk.pu.go.id" className="underline">LPJK</a>
          {' '}atau{' '}
          <a href="https://s.pu.go.id" className="underline">Ditjen Bina Konstruksi</a>.
        </p>
      </div>
    );
  }
  
  // Hanya render countdown jika tanggal valid
  return (
    <div className="bg-blue-50 border-l-4 border-blue-400 p-4">
      <h3 className="text-sm font-medium text-blue-800">{deadline.description}</h3>
      <CountdownTimer targetDate={deadline.deadlineDate} />
    </div>
  );
}
```

## 🧪 Test Cases untuk Verifikasi Implementasi

Jalankan 5 skenario pengujian ini untuk memastikan tidak ada kebocoran tenggat keliru:

### **Test 1: T2 Tetap Tersembunyi Saat Surat Belum Terverifikasi**
```
Given: SURAT_PASAL_20_STATUS.verified = false
When:  getTransitionDeadline('sbu_conversion') dipanggil
Then:  Return object dengan status='pending_verification'
       triggerDate = null
       deadlineDate = null
       message berisi penjelasan menunggu verifikasi
```

### **Test 2: T1 Tetap Ditampilkan Normal**
```
Given: SURAT_PASAL_20_STATUS.verified = false (tidak mempengaruhi T1)
When:  getTransitionDeadline('lsbu_adjustment') dipanggil
Then:  Return object dengan status='active'
       triggerDate = '2026-08-26'
       deadlineDate = '2027-02-25'
```

### **Test 3: UI Tidak Merender Countdown untuk T2**
```
Given: Komponen <TransitionExplainer type="sbu_conversion" /> di-render
And:   SURAT_PASAL_20_STATUS.verified = false
Then:  Tampil banner kuning "Tenggat Belum Ditetapkan"
       TIDAK ada elemen countdown/hitung mundur
       TIDAK ada tanggal yang ditampilkan
```

### **Test 4: Kedua Alur Tidak Tertukar di UI**
```
Given: Kedua komponen di-render berdampingan
When:  <TransitionExplainer type="lsbu_adjustment" />
       <TransitionExplainer type="sbu_conversion" />
Then:  T1 menampilkan countdown aktif (biru)
       T2 menampilkan status pending (kuning)
       Tidak ada tanggal T1 yang bocor ke T2
```

### **Test 5: Simulasi Pasca-Verifikasi (Untuk Kesiapan Future)**
```
Given: SURAT_PASAL_20_STATUS.verified = true
And:   expertReviewCompleted = true
And:   verificationDate = '2026-10-15' (contoh)
When:  getTransitionDeadline('sbu_conversion') dipanggil
Then:  Return object dengan status='active'
       triggerDate = '2026-10-15'
       deadlineDate = '2027-04-15' (6 bulan kemudian)
```

```markdown
### T1: Penyesuaian Skema LSBU (AKTIF)
- Dasar: Diktum KEEMPAT Kepdirjen 281/2026
- Pemicu: 26 Agustus 2026 (tanggal penetapan)

- Pemicu: Surat pimpinan unit organisasi bidang jasa konstruksi
- Status verifikasi:
  - [ ] Salinan surat diperoleh dari Ditjen Bina Konstruksi/LPJK
  - [ ] Nomor, penandatangan, tanggal, cakupan terverifikasi
  - [ ] Ahli skema/LSBU meninjau diktum KEEMPAT
  - [ ] Ahli skema/LSBU meninjau Pasal 20-21 dan pengecualian
- Status UI: ⏳ Ditampilkan sebagai "Tenggat Belum Ditetapkan"

### Prinsip Defensive Design
- Tenggat konversi TIDAK akan ditampilkan sampai kedua verifikasi selesai
- Tidak ada fallback ke tanggal Kepdirjen untuk T2
- UI akan gagal aman (fail-safe) dengan menampilkan status pending
```
