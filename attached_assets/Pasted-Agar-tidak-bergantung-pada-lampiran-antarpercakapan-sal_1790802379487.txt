Agar tidak bergantung pada lampiran antarpercakapan, **salin blok berikut dan simpan sebagai `ruang-simpan-profile-read.md`**, lalu unggah berkas itu di sesi SBU Accelerator.

Ini spesifikasi ringkas berdasarkan kode workspace Gustafta; **ketersediaannya pada deployment live belum saya verifikasi**.

```markdown
# Integrasi Ruang Simpan — profile:read

## Cakupan
Aplikasi SBU Accelerator hanya membaca profil resmi perusahaan.
Tidak meminta profile:write, files:read, atau files:write.

## Prasyarat
1. Pemilik login ke Gustafta.
2. Pemilik mengisi profil perusahaan di Ruang Simpan.
3. Pemilik membuat koneksi aplikasi dengan izin profile:read.
4. Token disimpan sebagai secret pada server SBU Accelerator.

Token hanya ditampilkan sekali, berlaku 90 hari, dan dapat dicabut.
Akun pemilik harus aktif.

## Permintaan

Metode: GET
Path: /api/v1/ruang-simpan/company-profile
Transport: HTTPS, server-ke-server

Header:
Authorization: Bearer <token-koneksi>

Tidak memerlukan body atau parameter user_id.
Identitas pemilik profil ditentukan oleh token koneksi.
Base URL deployment Gustafta harus dikonfirmasi sebelum integrasi live.

## Respons sukses — HTTP 200

Respons berupa objek langsung, tanpa pembungkus "profile":

{
  "name": "PT Contoh",
  "nib": "123456789",
  "address": "Jakarta",
  "revision": 1,
  "updated_at": "2026-10-01T00:00:00.000Z"
}

Jika profil belum diisi:

{
  "name": "",
  "nib": "",
  "address": "",
  "revision": 0,
  "updated_at": null
}

Header respons: Cache-Control: private, no-store

## Penanganan kesalahan
- 401: token salah, kedaluwarsa, dicabut, atau pemilik tidak aktif.
- 403: token tidak memiliki izin profile:read.
- 429: batas permintaan terlampaui.
- 503: izin atau profil tidak dapat diverifikasi/dibaca.

Batas kode saat ini:
- 60 permintaan per menit per koneksi.
- Pemeriksaan awal token juga dibatasi 60 per menit per IP.

## Aturan aplikasi SBU
- Token tidak boleh masuk frontend, URL, log, atau berkas unggahan.
- Jangan mengganti kegagalan API dengan data perusahaan rekaan.
- Jangan memperlakukan kegagalan API sebagai profil kosong.
- Gustafta tetap menjadi sumber resmi profil perusahaan.
- Panggilan browser langsung lintas domain tidak didukung.
```

Blok ini tidak mengandung token nyata dan tidak memberikan izin akses dokumen.
