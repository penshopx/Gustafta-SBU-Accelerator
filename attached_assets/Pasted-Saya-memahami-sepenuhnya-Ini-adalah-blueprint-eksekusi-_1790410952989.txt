### 📋 CHECKLIST EKSEKUSI TASK: Penentuan Tenggat Konversi SBU (T2)

#### **Fase 1: Verifikasi Dokumen Resmi (Single Source of Truth)**
*Tujuan: Memastikan dasar hukum yang digunakan adalah dokumen yang sah dan final.*
- [ ] **Peroleh Salinan Resmi:** Dapatkan salinan surat dari Ditjen Bina Konstruksi / LPJK yang merujuk pada Pasal 20 ayat (2) Permen PU 6/2025.
- [ ] **Validasi 5 Elemen Kunci:**
  1. **Nomor Surat:** (Catat untuk dokumentasi)
  2. **Tanggal Terbit Surat:** *(Ini adalah satu-satunya pemicu valid untuk awal hitungan 6 bulan T2)*
  3. **Penandatangan:** Pimpinan unit organisasi bidang jasa konstruksi.
  4. **Cakupan:** Memastikan surat ini memang mengatur pemberlakuan operasional/konversi SBU.
  5. **Status Terkini:** Memastikan tidak ada surat pembatalan atau penundaan setelahnya.
- [ ] **Cross-check Kepdirjen:** Konfirmasi status mutakhir Kepdirjen 281/KPTS/DK/2026 (pastikan tidak ada revisi yang mengubah diktum peralihan).

#### **Fase 2: Telaah Ahli (Expert Review)**
*Tujuan: Menerjemahkan bahasa hukum menjadi logika aplikasi yang aman.*
Minta ahli skema/LSBU untuk meninjau dan memberikan persetujuan tertulis atas 4 poin ini:
- [ ] **Diktum KEEMPAT:** Konfirmasi interpretasi batas waktu 6 bulan untuk LSBU vs 6 bulan untuk BUJK.
- [ ] **Syarat Operasional SIJK:** Konfirmasi bahwa infrastruktur SIJK Terintegrasi sudah siap menangani beban konversi massal pada tanggal tersebut.
- [ ] **Pasal 20–21:** Konfirmasi mekanisme konversi (tanpa asesmen ulang, masa berlaku mengikuti SBU lama).
- [ ] **Pengecualian Pasal 21 ayat (7):** Konfirmasi aturan untuk SBU yang sedang digunakan dalam proses pemilihan penyedia jasa atau pengikatan kontrak (SBU tetap berlaku sampai kontrak berakhir).

#### **Fase 4: Sinkronisasi Teknis (Code Sync)**
*Tujuan: Menerjemahkan keputusan ke dalam kode dengan prinsip fail-safe.*

**1. Update `artifacts/api-server/src/lib/sbu-rules.ts`**
Pastikan logika memisahkan T1 dan T2 secara ketat. T2 **harus** bergantung pada flag verifikasi, bukan tanggal Kepdirjen.

```typescript
// KONFIGURASI STATUS VERIFIKASI (Default: FALSE)
// HANYA ubah ini menjadi true DAN isi tanggal setelah Fase 1 & 2 selesai.
export const ARTICLE_20_VERIFICATION = {
  isVerified: false, 
  officialLetterDate: null, // Format: 'YYYY-MM-DD' (Tanggal surat, BUKAN tanggal Kepdirjen)
  expertReviewApproved: false,
  referenceDocument: "Menunggu surat resmi Pasal 20 ayat (2)"
};

export function getTransitionDeadline(type: 'lsbu_adjustment' | 'sbu_conversion') {
  if (type === 'lsbu_adjustment') {
    // T1: Pemicu adalah tanggal Kepdirjen (Sudah final)
    return {
      status: 'active',
      triggerDate: '2026-08-26', // Tanggal Kepdirjen 281/2026
      deadlineDate: '2027-02-25',
      description: 'Penyesuaian skema sertifikasi LSBU'
    };
  }
  
  if (type === 'sbu_conversion') {
    // T2: FAIL-SAFE. Jika belum terverifikasi, KEMBALIKAN NULL.
    if (!ARTICLE_20_VERIFICATION.isVerified || !ARTICLE_20_VERIFICATION.expertReviewApproved || !ARTICLE_20_VERIFICATION.officialLetterDate) {
      return {
        status: 'pending_verification',
        triggerDate: null,       // PENTING: Tetap null
        deadlineDate: null,      // PENTING: Tetap null
        message: 'Tenggat konversi SBU belum ditetapkan. Menunggu surat resmi Pasal 20 ayat (2) dan tinjauan ahli.'
      };
    }
    
    // HANYA dieksekusi jika sudah diverifikasi
    const trigger = new Date(ARTICLE_20_VERIFICATION.officialLetterDate);
    const deadline = new Date(trigger);
    deadline.setMonth(deadline.getMonth() + 6); // Tambah 6 bulan dari tanggal surat
    
    return {
      status: 'active',
      triggerDate: ARTICLE_20_VERIFICATION.officialLetterDate,
      deadlineDate: deadline.toISOString().split('T')[0],
      description: 'Konversi SBU eksisting (berdasarkan surat resmi)'
    };
  }
}
```
