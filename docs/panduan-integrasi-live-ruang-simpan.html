SBU ACCELERATOR · PANDUAN PENUTUPAN

Integrasi Gustafta / Ruang Simpan dibatalkan

Panduan ini menggantikan petunjuk aktivasi dan pengujian live lama. Jangan membuat token baru, menambah pemetaan, atau mengaktifkan ulang integrasi.

Status: pembatalan integrasi tidak membuktikan token sudah dicabut atau konfigurasi sudah dihapus. Penutupan belum dinyatakan selesai tanpa konfirmasi pemilik dan operator.

Yang tetap digunakan

Profil perusahaan lokal SBU dan penyimpanan dokumen mandiri yang juga bernama “Ruang Simpan” tetap utuh. Jangan menghapus profil, dokumen, akun, database, konfigurasi Clerk, atau App Storage.

Penutupan tidak memerlukan pembacaan profil Gustafta. Jangan menggunakan token lama untuk menguji sumber atau meminta pemilik mengirim profil perusahaan.

1. Persetujuan dan tanggung jawab

  • Pemilik: menyetujui pencabutan koneksi khusus integrasi yang dibatalkan dan penghapusan konfigurasi terkait; mengonfirmasi pencabutan setelah operator bertindak.
  • Operator Gustafta berwenang: memastikan koneksi/token tidak dipakai layanan lain, lalu mencabutnya di sistem sumber. Laporkan status saja, tanpa token atau ID koneksi.
  • Operator SBU: memeriksa penggunaan setiap nama konfigurasi, membersihkan hanya entri yang disetujui, dan memeriksa development serta production secara terpisah.

Jika tujuan koneksi, kewenangan, atau ketergantungan layanan lain belum jelas, hentikan penghapusan entri tersebut. Tidak adanya pemakai di kode SBU bukan bukti bahwa layanan lain tidak memakainya. Menghapus secret di Replit tidak mencabut token di Gustafta.

2. Inventaris tanpa nilai rahasia atau identitas

Catat hanya nama konfigurasi, lingkungan, keberadaan, dan status persetujuan. Jangan membuka nilai token atau isi pemetaan identitas; jangan menyalin environment, ID akun/koneksi, data perusahaan, cookie, HAR, atau tangkapan layar berisi data tersebut.

  • RUANG_SIMPAN_CONNECTIONS: pemetaan lama. Hapus hanya entri yang disetujui, tanpa menyalin ID ke laporan. Hapus seluruh variabel hanya jika semuanya khusus integrasi ini.
  • RUANG_SIMPAN_TOKEN_SBU: secret lama yang perlu diperiksa, bukan otomatis boleh dihapus.
  • RUANG_SIMPAN_TOKEN_*: periksa nama secret yang benar-benar tersedia. Jangan melakukan penghapusan wildcard.
  • SBU_RUANG_SIMPAN_ENABLED: jika ada dan khusus integrasi ini, hapus setelah persetujuan. Jangan mengaturnya ke true.
  • Periksa deklarasi proyek .replit secara privat agar pemetaan lama tidak muncul kembali. Jangan menyalin nilainya ke chat, diff yang dibagikan, atau laporan.

Periksa lingkungan development, production, konfigurasi shared yang diwariskan, dan pengaturan deployment aktif. Keberadaan secret pada pemeriksaan production tidak membuktikan konfigurasi proses production yang sedang berjalan.

3. Urutan pencabutan dan pembersihan

  1. Dapatkan persetujuan pemilik dan konfirmasi operator bahwa entri terkait tidak digunakan layanan lain.
  2. Operator Gustafta mencabut hanya koneksi/token integrasi yang dibatalkan; pemilik mengonfirmasi pencabutan tanpa menyebutkan nilai token atau identitas koneksi.
  3. Operator SBU menghapus pemetaan/variabel yang disetujui melalui Configurations resmi, termasuk deklarasi proyek terkait setelah persetujuan.
  4. Hapus secret yang disetujui melalui Tools → Secrets → menu entri → Delete. Jangan menggantinya dengan token palsu atau string kosong.
  5. Periksa Publishing → Adjust settings untuk secrets dan konfigurasi production secara terpisah. Penerapan atau publishing memerlukan persetujuan pemilik; jangan menerbitkan perubahan otomatis.
  6. Setelah perubahan development, restart workflow API sekali. Konfirmasi konfigurasi efektif layanan berjalan sudah bersih tanpa membuka nilainya.
  7. Jalankan regresi lokal: jalur integrasi lama tetap ditolak, sementara jalur profil dan dokumen lokal tetap tersedia. Jangan membaca profil sumber untuk verifikasi ini.

Referensi resmi: Secrets Replit dan Publishing.

4. Laporan penutupan

Status pemeriksaan 13 Oktober 2026:
  • Pemilik menyetujui pembersihan dan mengonfirmasi pernyataan operator bahwa koneksi sumber sudah dicabut serta tidak dipakai layanan lain. Tidak dilakukan pembacaan profil live.
  • Pemetaan RUANG_SIMPAN_CONNECTIONS dan flag SBU_RUANG_SIMPAN_ENABLED sudah dihapus melalui alur environment resmi untuk development, production, dan shared. Kedua nama tidak ditemukan lagi pada pemeriksaan konfigurasi development/production; deklarasi terkait di .replit juga sudah tidak ada.
  • Pemilik melaporkan penghapusan RUANG_SIMPAN_TOKEN_SBU melalui UI Secrets development. Pemeriksaan resmi terpisah kini tidak menemukan secret integrasi maupun kedua nama pemetaan/flag lama pada development, production, atau shared. Nilai token dan isi pemetaan identitas tidak dibuka.
  • API development berhasil direstart dan tiga regresi lokal lulus. Pembersihan konfigurasi yang dilaporkan alur environment resmi selesai. Deployment aktif tersedia, tetapi perubahan kode belum diterbitkan.
  • Pemeriksaan publik tanpa token pada jalur integrasi lama menghasilkan HTTP 401 JSON dengan Cache-Control: private, no-store, bukan HTTP 410. Ini bukan bukti kode penolakan integrasi sudah berlaku di production, maupun bukti isi environment proses production aktif. Verifikasi versi terpublikasi tetap pekerjaan terpisah; tidak dilakukan publishing, login, atau pembacaan profil live.
